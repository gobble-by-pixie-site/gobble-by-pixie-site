# Gobble by Pixie — storefront

- Astro static site, **vanilla CSS design tokens** (`src/styles/global.css`) — deliberately no Tailwind, no component library.
- **Design pivoted 2026-07-30** to an editorial style matching client-approved reference `miampatisserie.com`: muted dusty-rose/cream palette, sharp corners (not rounded pills), unified Cormorant Garamond/EB Garamond typography (dropped the earlier Playfair Display + colorful multi-hue direction). If you see references to a "colorful boutique" palette elsewhere (old commits, PLAN.md history), that's superseded — current tokens are the source of truth.
- Real brand assets in use: logo (`public/Logos/Gobble Logo-TM-Black.png` — black variant chosen for contrast against the light/cream site; red/white variants also present but unused), real product photography (`public/Cover photo.JPG`, `public/Green Jar.png`).
- Product/menu data: Google Sheet published as CSV — see `src/lib/fetchProducts.js`. Falls back to hardcoded placeholder products when `GOOGLE_SHEET_CSV_URL` isn't set, but **in production this is live**: a real 37-item catalog is being pulled from the client's Sheet right now.
- Site copy (hero eyebrow/sub/trust text, footer tagline, fulfillment banner, FSSAI/GSTIN, grazing-table price, about-page intro) is wired to the SiteContent tab (`src/lib/fetchSiteContent.js`, `GOOGLE_SITE_CONTENT_CSV_URL` env var) as of 2026-07-31 — she can edit the `value` column and rebuild+redeploy to update text without touching code. Falls back to hardcoded defaults per-key if the Sheet value is blank or the CSV fetch fails, so a half-filled Sheet can't break the site. **Use the standard gid-based `export?format=csv&gid=<id>` URL, same pattern as `GOOGLE_SHEET_CSV_URL`** — a `gviz/tq?tqx=out:csv&sheet=<name>` URL was tried first and looked more robust on paper (survives tab reordering) but Google's gviz export reproducibly squashed most rows of this exact sheet into one row while the gid-based export read it perfectly; root cause never identified, just avoid gviz here. Not yet wired: the H1 "Handmade Flavoured Cream Cheese" wordmark (kept hardcoded — it's split into two `<span>`s for the gradient effect, not a plain string) and the FAQ page's dispatch cards (structured differently from the banner's combined string, left as-is).
- Account/rewards system (`/account`, `/login`, `/signup`) uses localStorage session (`gbp_auth`, `gbp_customer`) + a Google Apps Script backend (`APPS_SCRIPT_URL` env var). **This backend is built, deployed, and verified working end-to-end in production** — `code.gs` in this repo is the deployed script (also mirrored in the client's Sheet's own Script Editor; keep both in sync manually, there's no CI push to Apps Script). Covers: signup/signin/password-reset, profile updates, points/tiers (Nibbler → Foodie → Gobbler VIP), get-orders, coupon validation, GST reverse-calculation on orders, and Razorpay webhook handling (order creation/refund/cancellation) — the Razorpay pieces are fully built but return a graceful "not set up yet" error until real API keys are added to `code.gs`'s `CONFIG`.
- **Cart**: `public/cart.js` is a plain-JS, localStorage-backed shopping cart shared across every page (loaded globally via a `<script>` tag in `BaseLayout.astro`, exposed as `window.GobbleCart`). Every "add to order" action on the site (homepage cards, menu Quick View modal, BYOP custom platters, account-page Reorder) adds to this cart, not a per-item WhatsApp link. Checkout currently builds one combined WhatsApp message from the cart contents — swap that step for real payment once Razorpay keys land.
- Full build plan, scope decisions, and BOS integration roadmap: `../PLAN.md` (one level up, shared with the non-website phases — this is a planning doc, not deployed with the site).
- **Deploy target**: Cloudflare Pages, project `gobble-by-pixie-site`, under the client's own `gobblebypixie@gmail.com` account (not a Linear Ventures account). Auth is OAuth login (`wrangler login`), not an API token — token auth hit a reproducible wrangler bug on this project, never root-caused, just avoid it. Deploys are a manual `npm run build` + `wrangler pages deploy dist` — no CI, no auto-rebuild-on-Sheet-edit yet (that's scaffolded in `code.gs` but has nothing to trigger without a Cloudflare Git-connected build).
- **Live domain**: https://gobblebypixie.com (cutover from Squarespace completed 2026-07-30/31 — DNS migrated to Cloudflare, SSL active, MX/email records preserved).
